# Ingress Leaderboard Telegram Bot - Detailed Project Summary

## 🎯 What This Project Is

The Ingress Leaderboard Telegram Bot is a comprehensive, open-source application designed to track and compare statistics from the Ingress augmented reality game. It provides a platform for Ingress agents (players) to submit their game statistics, view dynamic leaderboards, compare faction performance (Enlightened vs Resistance), track personal progress over time, and engage in competitive gameplay through Telegram chat interfaces.

Built with Python using the Telegram Bot API, it features local SQLite database storage, robust data parsing and validation, and an interactive user experience with features like auto-deleting messages for privacy and broadcast capabilities for administrators.

## 🚀 Key Features

### Core Functionality
- **Dynamic Leaderboards**: View rankings for daily, weekly, monthly, and all-time periods
- **Faction Competition**: Separate tracking and comparison for Enlightened (🟢) and Resistance (🔵) factions
- **Progress Tracking**: Individual agent progress comparison over specified time periods
- **Data Submission**: Interactive submission of Ingress statistics with enhanced validation
- **Local Storage**: SQLite database for persistent, offline-capable data storage

### Advanced Features
- **Enhanced Data Parser**: Intelligent field detection with confidence scoring (0-100%)
- **Spreadsheet-Style Display**: Professional table formatting with Unicode characters
- **Auto-Delete Stats**: Automatic deletion of user statistics messages to prevent copying and keep chats clean
- **Broadcast System**: Administrator capabilities to send announcements to all users
- **Concurrency Handling**: Improved handling of simultaneous user interactions
- **Direct Paste Support**: Restored ability to directly paste statistics without command prefixes

### Statistics Tracked (50+ metrics)
- Basic: Level, Lifetime AP, Current AP, Unique Portals Visited
- Discovery: Portals Discovered, XM Collected
- Combat: Resonators Deployed, Links Created, Control Fields Created, Mind Units Captured, Portals Captured
- Exploration: Distance Walked
- And many more specialized Ingress statistics

### User Interface
- Interactive inline keyboards for easy navigation
- Comprehensive help system with command documentation
- Error handling with user-friendly feedback
- Formatted output with emojis and visual indicators
- Multi-view options (summary, detailed, validation report)

## 📚 Quick Start Guide

### Prerequisites
- Python 3.8+
- Telegram Bot Token (obtained from @BotFather on Telegram)
- Virtual environment (recommended)

### Installation Steps

1. **Clone and Setup Environment**
   ```bash
   git clone <repository-url>
   cd ingress-leaderboard
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   pip install -e .
   ```

2. **Configure Bot Token**
   Create a `.env` file in the project root:
   ```
   BOT_TOKEN=your_actual_bot_token_here
   ```

3. **Optional Configurations**
   - `PREFIX_DETECTION_MODE`: strict/flexible (default: flexible)
   - `AUTO_DELETE_USER_STATS`: true/false (default: true)
   - `AUTO_DELETE_DELAY_SECONDS`: delay in seconds (default: 2)

4. **Run the Bot**
   ```bash
   bash scripts/run_bot.sh
   # or
   python main.py
   ```

### Testing
```bash
pytest
# or
python test_enhanced_system.py
```

### Key Components

#### Bot Service (`bot_service.py`)
- Manages Telegram bot lifecycle
- Handles message routing and command processing
- Integrates various services (database, parsing, formatting)

#### Database Layer (`database/`)
- `agents` table: Stores agent information and faction affiliation
- `submissions` table: Stores all statistical data with timestamps
- Optimized queries with proper indexing

#### Data Parsers (`parsers/`)
- **Original Parser**: Basic space-separated value parsing
- **Enhanced Parser**: Intelligent field detection, validation, confidence scoring
- Supports complex Ingress data formats including multi-word time spans

#### Services (`services/`)
- **Leaderboard Service**: Generates rankings and comparisons
- **Image Service**: Handles image processing for advanced features
- **Prefix Detector**: Intelligent command detection (strict/flexible modes)

#### Handlers (`handlers/`)
- **Command Handlers**: Process slash commands (/submit, /leaderboard, etc.)
- **Message Handlers**: Handle text messages and data submissions
- **Callback Handlers**: Manage inline keyboard button interactions
- **Enhanced Handlers**: Advanced processing with validation and formatting

### Data Flow Architecture
```
User Input → Command Detection → Parser → Validation → Database → Formatter → Response
     ↓             ↓             ↓         ↓           ↓         ↓           ↓
Telegram → Handler → Enhanced   → Quality → SQLite   → Table    → User
Message  → Router  → Parser     → Check   → Storage  → Format   → Interface
```

## 📊 Data Format and Validation

### Input Format
The bot accepts Ingress statistics in the following format:
```
ALL TIME AgentName Faction YYYY-MM-DD HH:MM:SS Level LifetimeAP CurrentAP UniquePortals ... [50+ stats]
```

Example:
```
ALL TIME TestAgent Enlightened 2025-01-15 12:30:45 16 50000000 25000000 3000 500 5 150 200000000 ...
```

### Enhanced Validation Features
- **Field Type Validation**: Ensures correct data types (int, str, date)
- **Range Checking**: Validates reasonable value ranges for each statistic
- **Confidence Scoring**: 0-100% reliability assessment
- **Error Detection**: Identifies potential data shifts or corruption
- **Smart Suggestions**: Provides correction recommendations

### Spreadsheet-Style Output
Data is presented in professional tables:
```
┌─────────────────────┬──────────────┬─────────────┐
│ Field               │ Value        │ Status      │
├─────────────────────┼──────────────┼─────────────┤
│ Agent Name          │ TestAgent    │ ✅ Valid    │
│ Faction             │ 🟢 Enlightened │ ✅ Valid    │
│ Level               │ 16           │ ✅ Valid    │
│ Lifetime AP         │ 50,000,000   │ ✅ Valid    │
└─────────────────────┴──────────────┴─────────────┘
```
